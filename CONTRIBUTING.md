# Contributing

Thanks for helping improve this Java practice repository.

## What to contribute
- Correct a bug or improve an existing example.
- Add a small, focused example for a Java concept.
- Improve explanations, naming, formatting, or beginner setup instructions.
- Include expected output when it makes an example easier to understand.

## Before opening a pull request
1. Keep each change focused on one concept.
2. Use clear class and method names.
3. Compile examples with a supported Java version when possible.
4. Explain what changed and how you checked it.
5. Avoid committing generated files, IDE settings, or unrelated changes.

## Pull request checklist
- [ ] The change has a clear purpose.
- [ ] Examples are readable and use consistent formatting.
- [ ] Any new behavior or output is explained.
- [ ] The description includes relevant testing or notes.

Beginner-friendly improvements and constructive feedback are welcome.
