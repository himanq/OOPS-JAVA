# Java OOP Practice Exercises

Use these exercises to test your understanding after studying the examples in this repository.

## Encapsulation
1. Create a `Student` class with private name and marks fields.
2. Add methods to update marks only when they are between 0 and 100.
3. Add a method that returns whether the student passed.

## Inheritance
1. Create a base `Vehicle` class with a `start()` method.
2. Extend it with `Car` and `Bike` classes.
3. Add one method unique to each child class.

## Polymorphism
1. Create a `Shape` parent class with an `area()` method.
2. Implement `Circle` and `Rectangle` classes.
3. Store both in a `Shape[]` array and call `area()` on each object.

## Abstraction
1. Define a `PaymentMethod` interface with a `pay(double amount)` method.
2. Implement it using `CardPayment` and `UpiPayment`.
3. Write a method that accepts any `PaymentMethod` and invokes `pay()`.

## Reflection
For each exercise, explain which OOP principle is being demonstrated and why. Compile and run your solution, then test at least one invalid or boundary input.
